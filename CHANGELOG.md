# Changelog

All notable changes to Vara will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses semantic versioning once public releases begin.

## [0.1.0] - Unreleased

### Added

- Multi-backend vector database debugging across Qdrant, pgvector, Milvus, and Pinecone.
- Core query debugging, backend comparison, health checks, and retrieval diagnosis.
- Eval harness with CSV, JSON/JSONL, and collection-sample dataset sources.
- Projection service with UMAP/t-SNE, 2D/3D modes, incremental projection, and clustering.
- FastAPI server, WebSocket streams, Typer CLI, and bundled React UI.
- Package build pipeline that bundles compiled UI assets into the Python wheel.
